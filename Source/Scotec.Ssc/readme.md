# Scotec SSC

Scotec SSC is a collection of .NET libraries designed to provide reusable components and utilities for a variety of application scenarios, including authentication, cloud integration, mathematical operations, logging, and more. The libraries target .NET 8, .NET Standard 2.0, and .NET Standard 2.1, ensuring broad compatibility across modern .NET applications.

## Main Libraries

- **Scotec.Identity.AzureActiveDirectory**: Provides authentication and token management for Azure Active Directory using MSAL, supporting secure token caching and integration with Azure SDK clients.
- **Scotec.Extensions.Utilities**: A set of helpful extension methods and utilities for .NET applications.
- **Scotec.Queues**: Task queue implementations for background processing and job management.
- **Scotec.Transactions**: Base classes for implementing transaction handling in non-database applications.
- **Scotec.Web.Robots**: Generates dynamic robots.txt and sitemap.xml files for Blazor websites.
- **Scotec.Math, Scotec.Math.Units**: Libraries for mathematical operations and unit handling.
- **Scotec.Extensions.Logging**: Logging extensions for .NET applications.
- **Scotec.Events.WeakEvents**: Implements weak event patterns to avoid memory leaks in event-driven code.
- **Scotec.XmlDatabase**: XML-based lightweight database utilities.

## Features

- Modern .NET support (net8.0, netstandard2.0, netstandard2.1)
- MIT licensed, open source
- Modular, reusable components
- Designed for cloud, desktop, and web applications
